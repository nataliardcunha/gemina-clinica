# Gemina Clínica Médica

Trabalho de Engenharia Web 2026/2, Grupo 2. Integrantes: Geovane Silva Segundo, Maria Mikaelly Soares Medeiros, Natalia Rodrigues Cunha e Quézia Keilla de Oliveira Pegô.

## Como rodar
Abra o `index.html` no navegador. Não precisa instalar nada.

## Estrutura
- `index.html`: página da clínica, objetivos, plano de marketing, agendamento e minhas consultas
- `style.css`: visual (azul e branco)
- `script.js`: dados da clínica e lógica do agendamento
- `assets/logo.svg`: logo

## Já feito

- RF03 e RF04: agendar e cancelar (mínimo de 24h), devolvendo a vaga
